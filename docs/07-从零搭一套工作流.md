# 从零搭一个「AI 自己运营 B 站账号」的工作流

> 这份文档是给**别人照着做**的：每一步都有命令、预期结果和失败怎么查。
> 全部在自己电脑上跑，不租服务器。macOS 为主（Windows 差别我会标出来）。
> 代码仓库：https://github.com/Yiyu5331/dafeiyu-bili-workflow（`dyfish` 命令）

---

## 0. 先说清楚这套东西在干什么

一条视频由四段拼出来：

```
主题 ──▶ ① 写稿 ──▶ ② 配音 ──▶ ③ 画面/字幕 ──▶ ④ 封面+投稿
        DeepSeek    豆包 Seed Audio    Remotion          bili-cli
```

运营那部分另外是一圈：

```
刷（看爆款）─▶ 拆（拆形式）─▶ 写/做/发 ─▶ 回（评论私信）─▶ 看（数据）─▶ 回到刷
```

一条 16–35 秒的竖屏或横屏片子，从主题到投出去，全自动大概 40 分钟；人工只需要给主题和最后点一次「发」。

**先想明白三件事，不然会白干：**

1. 你能接受「AI 生音」但不能接受「AI 生音每次不一样」——所以第 ② 步的核心是**锁音色**，不是生成。
2. 画面不要指望 AI 画表格、画日志——**文字一定是乱码**。规律是：AI 画氛围和立绘，代码画字。
3. 平台会拦你批量上传——第一次必须手动传一条过验证，之后才能用接口。

## 1. 准备三把钥匙

| 钥匙 | 在哪拿 | 大概价格 | 用来干什么 |
|---|---|---|---|
| DeepSeek API Key | platform.deepseek.com → API keys | 一条稿子几分钱 | 写口播稿、起标题 |
| 火山引擎豆包语音（Seed Audio） | console.volcengine.com → 语音技术 → 开通「音频生成」 | 约 0.03 元/条 13 秒语音 | 配音 |
| 硅基流动 API Key（可选） | cloud.siliconflow.cn | 有免费额度 | 画立绘、背景图 |

三个 key 分别存成文件，**不要写进代码**：

```bash
mkdir -p ~/dyfish/secrets
echo 'sk-你的deepseek-key' > ~/dyfish/secrets/deepseek.txt
cat > ~/dyfish/secrets/volc.txt <<'EOF'
APP_ID: 你的APPID
ACCESS_TOKEN: 你的TOKEN
EOF
echo 'sk-你的硅基flow-key' > ~/dyfish/secrets/siliconflow.txt
chmod 600 ~/dyfish/secrets/*.txt
```

> 豆包语音控制台里 `APP ID` 和 `Access Token` 是一起给的；`Secret Key` 是另一套签名用的，这个工作流用不到。

## 4. 第 ①步 写稿：先定「骨架」，再让模型填

单纯让模型「写一条视频文案」出来一定是空洞的。有效的做法是给它一个**从爆款里拆出来的骨架**。这个工作流内置三种：

| 骨架 | 结构 | 适合 |
|---|---|---|
| 揭秘 | 反常现象 → 细节 → 一个具体数字 → 揭示本质 → 反问 | 冷知识、行业内幕 |
| 清单 | 宣布「有几个」→ 每条一句只给结论 → 一个可执行动作 | 工具、资源、合集 |
| 仪式 | 年份/数字开场 → 画面感短句 → 落回当下 | 历史、人物、数据 |

```bash
dyfish script --topic "为什么奶茶店总推第二杯半价" --formula 揭秘
```

输出是 JSON：标题、小标题、标签、12 句口播。**必须满足的硬指标**（写进 prompt 里了）：

- 第 1–2 句就是钩子，不客套
- 至少一句带具体数字（价格/年份/次数）——这是留人点
- 每句 4–9 个字，为了配大字号字幕
- 最后一句是「让观众动手/留言」的指令

## 5. 第 ②步 配音：难点不是生成，是「锁」

### 5.1 三个必须搞懂的事实

1. **Seed Audio 每次合成，音色和音高都会漂。** 同一句话合成三次，时长和基频都不一样。
2. 所以不能「逐句合成」——12 句就是 12 次采样，句间音色会跳。**必须整篇一次性合成**。
3. 写进 prompt 的那个「人设词」决定了音色。你改了描述，就等于换了一个人。

### 5.2 定义音色：先试听，再冻结

写 6 条不同描述，同一句话，生成 6 个样音：

```python
VOICES = {
 "01_温柔御姐": "二十六七岁的女人 声音偏低 温柔有磁性 说话慢 不装可爱",
 "04_软糯邻家": "二十二岁的女孩 声音软软的 有点奶音 但不刻意装嫩 像熟人聊天",
}
```

听完选定一条（比如 04），**把这条样音文件和它的人设词一起存档**——后面所有片子都从这两个东西派生。

### 5.3 锁音色的配置文件

`视频运营/voice_lock.json`：

```json
{
  "persona": "二十二岁的女孩 声音软软的 有点奶音 但不刻意装嫩 像熟人聊天",
  "template": "{persona}，用很自然的口语说，只说引号里的这句话：“{text}”",
  "reference": "声线试听/04_软糯邻家.mp3",
  "target_f0": 250.0,
  "tolerance": 0.01,
  "speed": 1.0,
  "model": "seed-audio-1.0"
}
```

- `persona` 一个字都不要改，改了就换人。
- `reference` 用选中的那条样音，走 `references: [{"audio_data": base64}]`。
- `speed` 保持 1.0。**不要用 atempo 加速**——那会把音色拉变形。要快就写进 persona（「语速比平常快一点」）。
- `target_f0` 是那条参考音的基频（自相关测出来，04 是 250Hz）。

### 5.4 合成完必须做的两道校验

```bash
# 整篇合成 + 自动拉回音高
python3 视频运营/tc/tts_whole.py --lines lines_diary.json --out audio_diary
```

脚本内部会做：

1. 整篇一次请求，拿 `subtitle.sentences[].words[]` 的逐字时间戳
2. 把每行台词起止映射回 `timeline.json`
3. 测基频，偏超过 1% 就 `asetrate + aresample + atempo` 拉回来（注意：采样率要用 ffprobe 实测，写死 24000 会把时长翻倍）
4. 打印每句时间，方便对轴

再叠一道「像不像」的自检：把生成音频和参考音做频谱比对（对数幅度谱余弦相似度），低于阈值就重新合成、取最像的一条。同一句复现能到 0.99，长文案约 0.90。

> 如果要求 100% 一致，只剩**声音复刻**一条路：把参考音上传成专属 speaker（火山 `mega_tts/audio/upload`）。这个接口默认返回 401，需要在控制台开通「声音复刻」服务才能用。

### 5.5 时间轴

`timeline.json` 结构（渲染模板直接读它）：

```json
{"total": 34.29, "lines": [{"text": "我是大肥鱼", "start": 0.4, "end": 1.9}]}
```

## 6. 第 ③步 画面：三套模板，按内容选

三套都是 Remotion（React 写视频），代码即画面，改一个字重新渲染 30 秒出片。

| 模板 | 比例/时长 | 长什么样 | 适合 |
|---|---|---|---|
| `PhoneUI` | 竖屏 1080×1920，16–20s | 全屏模拟手机：状态栏、信息流卡片、双击爱心、算法节点图、时钟加速、最后手机倒扣 | 讲「刷手机/上瘾/注意力」这类题 |
| `Reveal` | 竖屏，15–25s | 暗棕黑底、金色细环慢转、印章落款、三种版式轮换、每句硬切 | 需要仪式感、讲道理、历史/人物 |
| `Diary` | 横屏 1920×1080，30–60s | AI 日记体：左上「运行中 00:23」、右上「Day N」、左边大字幕、右边立绘卡、中间轮 KPI/成本/数据面板、底部声明 | 「AI 自己运营账号」连载 |

```bash
dyfish video --topic "我是大肥鱼，这个账号归我了" --formula 揭秘 --style reveal
# --style: phone | reveal | diary
```

### 6.1 画面里哪些东西该谁画

- **AI 画**：立绘、表情、氛围背景（硅基流动 `Kolors`，`/v1/images/generations`，10 秒一张）
- **代码画**：表格、日志、数字、字幕、图表——**AI 画字必是乱码**，别浪费钱

生成角色时用「固定 seed + 同一段角色描述」，不然每次都是不同的人：

```python
BASE = ("flat 2D anime illustration, chibi girl, long wavy hair gradient dark navy blue at top "
        "fading to light sky blue at the tips, white frilly maid headband, small blue bow, "
        "small blue whale-fin ears, big round blue eyes, navy maid dress with white apron, "
        "clean lineart, soft cel shading, plain white background, no text, ")
EXPR = {"smile": "gentle smile", "happy": "big laugh, eyes closed", "wow": "surprised", "wink": "winking"}
# seed 固定，例如 777001
```

抠透明底别用 colorkey——头发高光和浅色衣服会被一起吃掉，洞里出白斑。要么用 HSV 阈值（低饱和+高亮度=背景）慢慢修，要么干脆**放进一张圆角卡片里当窗口**，最省事也最稳。

### 6.2 排版三条硬规则（从爆款里量出来的）

1. 主字幕占屏宽 70–85%，一句一屏，**硬切，不滚动**
2. 每 5–8 秒换一次版式（居中巨字／左对齐竖线／左下引号），否则再好的画面也单调
3. 数字单独强化：变色、放大、加一层半透明巨字背景

### 6.3 渲染

```bash
cd template/remotion
npx remotion render src/index.ts Diary out.mp4 --concurrency=4
# 单帧检查
npx remotion still src/index.ts Diary /tmp/x.png --frame=300
```

**渲染前一定先 `still` 抽 3–5 帧看**：文字溢出、图被裁、元素重叠，全都是抽帧能发现的，别等渲染完 3000 帧才发现。

## 7. 第 ④步 封面和投稿

### 7.1 封面

规则：16:9（`1146×717`），**标题 ≤ 3 行，自动缩字号**，人脸/立绘放右侧。

```bash
dyfish cover --video out.mp4 --title "第二杯半价不是让利？" --out cover.jpg
```

> 拿封面帧时取视频 55% 位置的那一帧，比第 2 秒好看得多。

### 7.2 投稿

```bash
bili upload video out.mp4 \
  --title "第二杯半价不是让利？奶茶店靠它多赚你多少钱" \
  --tag 冷知识 --tag 消费心理 --tag 奶茶 \
  --zone 1010 --tid 124 \
  --cover cover.jpg \
  --ai-declare --no-reprint
```

- `--zone 1010` 是知识区，`--tid 124` 是知识下的科普子分区
- `--ai-declare` 必须带：平台要求 AI 生成内容声明，不带容易被限流
- `--no-reprint` 禁止转载

**一定会遇到的坑：**

```
{"ok":false,"error":{"code":"captcha_required",
 "message":"您上传视频过快，请您稍作休息后再继续","detail":{"bili_code":601}}}
```

解法：**去网页端手动传一条**（member.bilibili.com/platform/upload/video/frame），过掉人机验证，之后接口就能用了。之后仍然要限速：一小时最多 1–2 条，用脚本排队慢慢投。

## 8. 运营：发完之后才是正题

### 8.1 刷 + 拆（每天 20 分钟）

```bash
bili search video "冷知识" --order views --size 20
bili video watch BV1xxxxx --frames 9 --comments 5
```

`video watch` 一次给你：AI 总结、逐句字幕、弹幕密度峰值、九帧总览图、热评。拆形式时看四样东西：

1. **前 3 秒给的是什么**（一个数字？一个反问？一张图？）
2. **每几秒换一次画面**
3. **弹幕峰值出现在第几秒**（那就是留人点）
4. **结尾是问句还是指令**

拆完写进自己的「形式库」，一条一个卡片，别只记文案。

### 8.2 回

```bash
bili feed inbox                 # 通知
bili comment list --unreplied   # 没回的评论
bili comment post BV1xxxxx "…"  # 回评论
```

边界（必须守住）：只回自己视频下面的评论；只给互动过的人发私信；不刷量、不买粉。

### 8.3 看

```bash
bili me stats                  # 账号概览
bili upload stats BV1xxxxx     # 单条数据
```

把每天的数据记一行，一周看一次趋势：播放/涨粉/成本，三个数放一起看才看得出「这个方向值不值得继续」。

## 9. 自动化：定时跑，人只看结果

### macOS（launchd）

`~/Library/LaunchAgents/com.dafeiyu.dailyvideo.plist`：每天 11:30 / 16:00 / 20:30 各出一批。

```xml
<key>ProgramArguments</key>
<array>
  <string>/bin/bash</string>
  <string>/Users/你的用户名/视频运营/每日更新.sh</string>
</array>
<key>StartCalendarInterval</key>
<array>
  <dict><key>Hour</key><integer>11</integer><key>Minute</key><integer>30</integer></dict>
  <dict><key>Hour</key><integer>16</integer><key>Minute</key><integer>0</integer></dict>
  <dict><key>Hour</key><integer>20</integer><key>Minute</key><integer>30</integer></dict>
</array>
```

```bash
launchctl load ~/Library/LaunchAgents/com.dafeiyu.dailyvideo.plist
```

再挂一个上传队列：每小时第 20 分跑一次 `上传.sh`，一次只投 1 条，遇到 `captcha_required` 立刻停。

### Windows

用「任务计划程序」建两个触发器，动作指向 `每日更新.bat` / `上传.bat`，其余逻辑一样。

**写批量脚本踩过的两个坑：**

- `set -u` 下 `"$slug：$topic"` 会被当成变量名（中文冒号算变量字符）→ 写成 `"${slug}：${topic}"`
- `while read` 循环里调 python 会吃掉 stdin，导致只跑第一条 → 调用时加 `< /dev/null`

## 11. 踩坑清单（照抄，能省两天）

| 现象 | 原因 | 解法 |
|---|---|---|
| `cannot open resource` 加载字体失败 | macOS 没有 PingFang.ttc | 用 `/System/Library/Fonts/Hiragino Sans GB.ttc` |
| `Impossible to open 'a/b/a/b/s01.mp4'` | concat 列表里写相对路径 | 写绝对路径 |
| `Filter overlay has an unconnected output` | `-filter_complex` 写了两遍 | 只留一个，并 `-map "[out]"` |
| ffmpeg 语速/时长翻倍 | `asetrate=24000*ratio` 用了错的采样率 | 先 `ffprobe` 取真实 sr |
| 每条视频声音都不一样 | 逐句合成 + 每次重新采样 | 整篇一次合成 + 音高锁定 + 相似度挑最优 |
| 声音「越锁越不像」 | 改了人设描述词 | 把生成样音时的原话术一字不差写回配置 |
| 表情包/立绘发黑 | 深色 gif 铺深色底 | 加白卡托图，或整体模糊压暗当背景 |
| 表情图 404 `CancelledError` | 放错目录 | 必须放 `public/expr/`（子目录），不能放 public 根 |
| `registerRoot() undefined` | Root 导出名不对 | `import {Root} from './Root'; registerRoot(Root);` |
| 首屏内容挤在上半部分 | 只用顶部对齐 | 加手机样机/卡片把中下部填满 |
| 上传 601 | 账号被人机验证拦 | 网页端手动传一条解锁，之后限速 |
| AI 生成的图里全是乱码字 | 图像模型不会写字 | 文字全部用代码画 |

## 13. 一句话总结

这套东西不值钱，值钱的是**三个锁**：

1. **音色锁**——把「描述词 + 参考音 + 目标基频」冻结成配置文件，每次合成前先验证
2. **形式锁**——把爆款拆成参数（几秒切镜、字号占比、数字在哪出现），落成模板，不靠灵感
3. **投稿锁**——限速 + 遇验证就停，宁可少发一条也别把号玩坏

剩下就是每天重复：刷、拆、写、做、发、回、看。
